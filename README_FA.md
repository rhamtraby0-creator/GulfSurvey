# سامانه نظرسنجی پالایش گاز بیدبلند خلیج فارس

سامانه سازمانی حرفه‌ای برای سنجش رضایت از وعده غذایی ناهار.

## ویژگی‌ها

- پنل نظرسنجی کاملاً فارسی و راست‌چین
- ۱۱ سؤال اجباری + بخش پیشنهاد و انتقاد اختیاری
- شناسه اختصاصی خودکار برای هر پاسخ (بدون نیاز به اطلاعات شخصی)
- پنل مدیریت امن با رمز قوی، قفل تصاعدی و نشست محدود
- داشبورد آماری زنده با نمودارهای Chart.js
- خروجی Excel، CSV و PDF
- پشتیبان‌گیری از پایگاه داده
- مرکز سلامت فنی سامانه
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## نصب سریع (Termux / لینوکس)

```bash
pkg update
pkg install python unzip
unzip GulfSurvey.zip
cd GulfSurvey
bash scripts/setup.sh
bash scripts/start.sh
```

پس از اجرای `setup.sh`، **رمز اولیه پنل مدیریت** فقط یک‌بار در ترمینال نمایش داده می‌شود. آن را یادداشت کنید.

## آدرس‌ها

| بخش | آدرس |
|-----|------|

## امنیت

- رمز عبور با bcrypt هش می‌شود
- هیچ IP، اثر انگشت یا اطلاعات شخصی ذخیره نمی‌شود
- فقط ۱۱ پاسخ + بازخورد اختیاری + شناسه + زمان ثبت نگهداری می‌شود
- محافظت در برابر XSS، CSRF و SQL Injection
- محدودیت تلاش ورود ناموفق با تأخیر تصاعدی

## تغییر رمز

از منوی «تنظیمات امنیتی» در پنل مدیریت.

## پشتیبان‌گیری

از منوی «نسخه پشتیبان» یا کپی دستی فایل `data/survey.db`.

## توقف سرویس

```bash
bash scripts/stop.sh
```

یا `Ctrl+C` در ترمینال اجرا.

## اتصال به زیرساخت ابری (Google Cloud Run)

1. یک Dockerfile بسازید که `uvicorn` را اجرا کند.
2. متغیرهای محیطی را تنظیم کنید.
3. برای تولید از PostgreSQL استفاده کنید و `DATABASE_URL` را تنظیم نمایید.
4. HTTPS را از طریق Cloud Run فعال کنید.
